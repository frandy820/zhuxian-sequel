# 诛仙·续作

> 狐岐山的雪落了三日。原著合上之后，铃还响着。

一部 **130 章 · 约 55 万字** 的《诛仙》非官方续篇，从原著终章之后写起：山崩了，宗门成了坟，守灵人点起第一盏灯——而一口缺了舌的铃，将把所有人的恩怨、债与执念，慢慢引回青云山下。

---

## 这是一部什么样的续作

- **五卷本长篇**：卷一《残铃》→ 卷二《断剑》→ 卷三《巫疆》→ 卷四《归墟》→ 卷五《渡》，全书完结。
- **一个"渡魂"的故事**：人间设灯册、开渡口，亡魂经此而渡；一口无舌之铃悬在井上，温一度一度地收——铃响一声，便是一个执念的解处。
- **原著人物的余波**：草庙村的旧案、通天殿上的峰会、剑冢的异动、河阳的灯市……原著留下的因果，在这里一桩一桩被"收账"。
- **小人物撑起的正场**：守陵的幽姬、开卦摊的周一仙、渡口边的杏儿——不写天崩地裂，写的是四百年里，一群人如何把一件事做到"两讫"。
